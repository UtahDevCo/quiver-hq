# Meta brain — always-on index

Higher-order practices that apply to **every** project. This index is loaded
into every session; the linked concepts are not. Read a concept in full before
relying on it, and prefer it over your own defaults.

A project may narrow, extend, replace, or suspend anything here via a
`Practice Override` in `brain/projects/<name>/overrides/`. When working inside a
project, resolve overrides first — `/brain-recall` does this for you, or read
`<project>/.brain/index.md` directly.

Governance, override resolution, and the local extensions are specified in
[conventions](../conventions.md).

# Using the brain

* `/brain-recall <topic>` - resolve practices for the current project and answer.
* `/brain-push "<learning>"` - record something worth keeping into the inbox.
* `/brain-harvest <project>` - extract knowledge from a repo into the inbox.
* `/brain-promote` - review the inbox and place concepts (human gate).
* `/brain-audit` - run attesters, surface stale and unverified concepts.
