# workflows

Repeatable processes: review loops, triage, evidence handling.

* [corroboration-requires-independent-sources](corroboration-requires-independent-sources.md) - Two sources only corroborate if they are independent. Diff their convention docs before counting them twice — generated and copied files make one document look like two.
* [pair-both-arms-in-one-window-or-drift-picks-the-winner](pair-both-arms-in-one-window-or-drift-picks-the-winner.md) - A control group fixes selection bias and nothing else. Capture both arms as adjacent calls per item, report discordant counts, and pool two runs before deciding.
