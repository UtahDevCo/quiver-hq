# Workflows

How to run a piece of work, when getting the order wrong is what costs you.

* [corroboration-requires-independent-sources](corroboration-requires-independent-sources.md) - Before counting two repos as agreement, diff their convention docs. Generated or copied files make one document look like two, and the check costs one grep.
* [pair-both-arms-in-one-window-or-drift-picks-the-winner](pair-both-arms-in-one-window-or-drift-picks-the-winner.md) - Comparing a fresh capture against a stored baseline lets provider drift masquerade as a treatment effect, and a control group cannot detect it because the control sits in the same degraded window. Capturing both arms as adjacent calls reversed the sign of a real decision, twice.
* [rank-the-documents-before-building-from-them](rank-the-documents-before-building-from-them.md) - A 265-line knowledge base, the newest and clearest file in the folder, described a transaction the executed contract forbids. Write the authority ranking into the repo as step one.
